# Oblig 4 - Basic Flask application

Dette er en enkel Flask applikasjon laget i faget DTE 2509 Databaser og webapplikasjoner.

Jeg har laget den ved hjelp av Flask, html-templates, base template med header og footer-templates, statiske filer og Bootstrap, og navigasjon med url_for(). Har laget den mobilvennlig, og brukt tokens for alt fra spacing til typographi med Clamp for variable størrelser etter skjermstørrelse.
